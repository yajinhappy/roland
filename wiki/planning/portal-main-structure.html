메인은 좌측 열을 수용. 우측 열은 각 서비스가 연결되는 기반이며 유저 노출 대상이 아님. 메인에서 솔루션이 드러나는 지점은 로그인 · 가입 2개로 충분.

현행 메인 구성의 문제

계정 연결 모듈이 메인 우측 사이드를 점유하고, 연결 계정 수 · 기록 축적률 등 내부 성과 지표가 유저 화면에 노출된 상태. 커뮤니티는 GNB와 메인 대형 블록을 동시 점유. 벤치마크 3곳에 동일 사례 없음. 특히 계정 연결을 배치한 자리에 Marvel은 뉴스를 배치.

GNB 재구성

기존 서브 콘텐츠 7종을 그대로 유지. 현재 메인인 3D 광장은 GNB 항목이 아니라 액션 버튼으로, 계정은 유틸리티 바로 분리. 생태계 플랫폼 3종을 유틸 좌측에 상설 노출.

PLAZA 를 GNB 에 두지 않은 이유

  • 「보는 곳」이 아니라 「들어가는 곳」. 나머지 7개는 읽고 훑는 지면이고 프론테라 광장은 3D 공간에 진입하는 행동. 같은 줄에 나열하면 성격이 섞임
  • 메뉴로 두면 8번째 칸에 묻힘. 벤치마크 3곳에 없는 유일한 차별 자산인데 평면 나열의 한 칸이 되면 무게가 사라짐
  • 채움 버튼 하나로 구분. 라이브 점 · 접속자 수는 표기하지 않음 — 실제 인원이 적을 때 오히려 부실해 보임
  • 스크롤하면 하단 앵커로 승계. PC 는 260px 에서 원형 버튼으로 내려오고 상단 90px 이내로 돌아와야 사라짐. TABLET · MO 는 처음부터 우측 하단 확장형 FAB
  • 명칭은 세 폭 모두 「프론테라 광장」. GNB 항목이 아니므로 영문 표기를 따르지 않고 「자세히 보기」 「전체보기」와 같은 행동 어휘

메인 구성

메인은 GNB의 미러가 아님. 벤치마크 3곳 모두 GNB 항목 전체를 홈에 블록으로 두지 않음. 배치 기준은 메뉴 목록이 아니라 방문한 유저가 첫 화면에서 던지는 질문.

구성안

1지금 무슨 일이 — HERO캠페인 5건 고정 · 자동 회전 없음. 제목은 타이틀명이 아니라 캠페인 · 이슈(Marvel 도 작품명이 아닌 THIS WEEK'S NEW COMICS를 제목으로 씀). 타이틀명 자리에는 글자 대신 타이틀 로고 아트를 크게 — 로고 안에 이미 「라그나로크」가 있어 이것만으로 포털 브랜드가 붙음(Star Wars 가 STAR WARS + 작품 로고를 한 덩어리로 쓰는 방식). 제목 위 지역 라벨로 어느 지사 소식인지 표기. CTA 는 「자세히 보기」 하나 — 레퍼런스는 2개이나 캠페인마다 행동이 달라 라벨이 제각각이 됨.
2뭘 플레이할 수 있나 — RO GAMES대표 카드 1종(라그나로크 온라인)을 히어로와 같은 문법으로 — 큰 키비주얼 + 타이틀 로고 아트 + CTA. 그 아래로 주요 타이틀 4장이 겹쳐 올라옴. 겹침이 묶음을 만들어 그룹 라벨이 필요 없음. 나머지는 전체보기. 범위는 RO IP 타이틀 전체 · 전 리전. 카드에는 썸네일 · 타이틀명 · 플랫폼 셋만 — 플랫폼은 영문 텍스트(PC · MOBILE), 아이콘을 쓰지 않음. 출시연도 · 지역 수는 두지 않음. 상태 배지는 CBT · 사전등록 · 서비스 예정만 표기하고 「서비스 중」은 생략.
3지금 바로 해볼 수 있나 — PRONTERA 구 3D 광장RO GAMES 직후. 게임 소개 다음에 「받지 않고도 여기서 해볼 수 있다」로 이어지는 흐름. 1행 배너가 아니라 풀블리드 섹션 — 벤치마크 3곳에 없는 유일한 차별 자산이므로 축소하지 않음. 게스트 진입이므로 「로그인 없이 둘러보기」를 CTA 에 명시. 하위 칩 3개(광장 탐험 · 하우징 · 코스튬 시뮬레이터). 접속자 수 · 라이브 점은 표기하지 않음 — 실제 인원이 적을 때 오히려 부실해 보임. 탭하면 바로 진입하되 전환 화면 필수 — 3D 로딩 동안 빈 캔버스가 뜨면 장애로 읽힘.
4뭐가 새로운가 — NEWS + MEDIA갱신 주기가 짧은 둘을 한 구역에. 좌측 NEWS 기사 리스트, 우측 MEDIA 최신 영상. NEWS 는 자체 발행이 아니라 글로벌 매체 보도 모아보기이므로 매체명 표기 필수이고 제목은 원문 언어 그대로. 타이틀 필터를 블록 상단에 노출(전체 + 주요 타이틀 4 · 로그인 시 연결 게임이 기본값). TABLET · MO 는 하위 영상 그리드를 두지 않고 대표 영상 1건 + 전체보기.
5뭘 찾아볼 수 있나 — LIBRARY 2차데이터 규모가 커서 카드 나열로는 대표성이 없음. 큰 검색창 + 대분류 6개(몬스터 · 아이템 · 맵 · NPC · 펫 · 직업). 정식 명칭은 룬 미드가츠 도서관. 조회 목적의 유입 비중을 고려해 상단 유틸 검색과 별개로 메인에 검색 진입을 한 번 더 배치.
6푸터정책 문서 9종 · 쿠키 설정 · 언어 셀렉터 · STORE 링크 · 저작권 표기(세 폭 모두).
모바일에서의 순서

글로벌 게임 IP 포털은 모바일 유입 비중이 큼. RO GAMES 가 세로로 길어져 PRONTERA 도달이 늦어지므로 주요 타이틀을 가로 레인(카드 폭 172)으로 눕히고 전체보기로 축약. LIBRARY 는 순서를 올려 PRONTERA 다음 · NEWS 앞에 배치 — 정보 탐색 목적의 모바일 접근이 많음. 검토 사항이 아니라 확정.

지역을 거르지 않는 이유

지사 사이트는 자기 지역만 보여줌. 포털이 접속 지역으로 콘텐츠를 걸러내면 지사 사이트와 같아져 존재 이유가 사라짐. 전 세계에서 무엇이 도는지 한 화면에 놓을 수 있는 것은 포털뿐. 따라서 거르지 않고 지역 라벨을 붙이고 순서만 바꿈 — 접속 지역을 위로 올리되 나머지도 그대로 노출. 히어로 탭 카드 5장에도 같은 라벨을 두어 전 지역이 한눈에 보이게 함.

메인에 블록을 두지 않는 항목

GNB 7개 중 4개와 PRONTERA 를 제외하면, 메인에 상설 블록을 두는 것은 4개. 상시로 보여줄 만큼 갱신되지 않거나, 다른 블록이 이미 그 역할을 하기 때문. 메인 블록은 6개로 벤치마크 밀도와 동일(Marvel 6, Star Wars 3~4).

항목메인 처리사유
RO IP GNB 첫 칸으로만 벤치마크 3곳 모두 홈에 IP 소개 블록을 두지 않음. IP 정체성은 HERO · 타이틀 섹션 · 화면 톤이 이미 전달하며, 스크롤 끝의 연혁 · 숫자 블록은 회사 소개 문법이지 IP 포털 홈 문법이 아님
RO FESTA 시즌에 HERO 탭 · NEWS로 노출 시즌 콘텐츠. 비시즌에 상설 블록을 두면 빈 배너가 됨
ORCHESTRA MEDIA 블록 안에서 노출 GNB에서 MEDIA 하위로 이동한 것과 동일한 처리. 신규 음원은 NEWS로도 노출
STORE 푸터 링크 · 신상품은 NEWS로 상시 프로모 배너는 갱신 부담이 크고 IP 포털의 첫 인상과 어긋남. 벤치마크도 상거래를 홈 상단에 두지 않음
체험형 → 포털형 전환의 핵심

현행 메인은 3D 광장 전체 화면으로, 검색 · AI가 수집할 본문이 없고 콘텐츠 진입이 NPC 도크에 종속. 포털형에서는 메인이 발신 지면 역할을 맡고 3D 광장은 PRONTERA 라는 하나의 콘텐츠 축으로 이동. 3D 자산은 폐기가 아니라 계층 이동이며, 하우징 · 코스튬 시뮬레이터가 그 안에서 확장.

계정과 솔루션의 위치

삭제가 아닌 이동. 기능은 유지하고 노출 위치만 변경.

대상이동 위치사유

생태계 서비스의 자리

경영진 전략 문서가 포털을 「모든 서비스로 접속하는 허브」로 정의. 포털은 종착지가 아니라 환승역이며, 성공 지표는 체류 시간이 아니라 다음 서비스로 얼마나 넘겼는가에 있음.

층위항목성격
포털이 가진 콘텐츠 RO IP · RO GAMES · LIBRARY · NEWS · MEDIA · RO FESTA · STORE · PRONTERA 포털 안에서 소비. GNB의 본래 대상
포털에서 나가는 서비스 RO 게임 타이틀군 · AIWAN · ROBOX · RO UGC · STORE 외부 이동. 생태계 확장에 따라 계속 늘어남

두 층위를 GNB 한 줄에 함께 두면 8칸 제약에 걸려 일부가 드롭다운이나 하위 페이지로 밀림. 자리 배분이 아니라 층위가 섞인 문제이며, 전략상 서비스가 추가될수록(Marketplace · Academy · Labs) 같은 충돌이 반복됨.

대상배치근거
AIWAN · ROBOX 유틸 바 좌측 배지 Star Wars KIDS — 관객이 다른 자매 플랫폼. 상설 노출되며 GNB 자리를 쓰지 않음
STORE 유틸 바 우측 강조 Marvel Unlimited. 수익 동선은 GNB에 두지 않되 시각적으로 구분
RO UGC 유틸 바 좌측 배지 별도 서비스로 구축 예정이므로 AIWAN · ROBOX와 같은 층위. 창작 축이 GNB를 쓰지 않고 확보됨
신규 서비스 오픈 프로모 밴드 Marvel Disney+ 밴드. 상설 메뉴를 건드리지 않고 시점성 유도
  • 나가는 길은 넷. 게임 · 창작 · 상거래 · 계정. 메인의 모든 CTA가 이 넷 중 하나로 향해야 함.
  • 유틸 바를 좌우로 나눠 규칙을 읽히게 함. 좌측은 다른 서비스로 갈아타기(AIWAN · ROBOX · RO UGC), 우측은 「나에 관한 것」(검색 · 언어 · STORE · 계정). STORE를 좌측에 합치면 수익 동선이 플랫폼 배지 사이에 묻히고, 향후 Marketplace · Academy가 추가될수록 더 희석됨.
  • 배지는 높이 고정 · 폭 가변 · 마크 자리 확보. 브랜드가 확정되면 로고가 들어가야 하므로 현재 명칭의 텍스트 폭에 맞춰 고정하지 않음. 브랜드명이 기능을 설명할 필요는 없음 — 첫 방문자용 한 줄 설명은 hover로 처리.
  • 상단 검색은 입력창이 아니라 아이콘. 벤치마크 3곳 모두 상시 입력창을 두지 않음(Marvel 아이콘 1개, Star Wars 아이콘 + 라벨). 입력창을 걷어낸 폭이 좌측 배지 자리가 됨. 검색 진입은 메인 LIBRARY 블록이 주로 담당.
  • GNB는 7개. 창작이 유틸로 빠지면서 GNB에 별도 창작 항목을 만들 필요가 없어짐.
  • 외부 이동은 표시로 구분. 포털 콘텐츠 링크와 섞이지 않도록 ↗ 등 최소 장치 적용.
  • 창작이 독립 축. 전략 문서의 6개 유저 분류 중 Creator가 별도 항목이나 현행 구조에 진입로가 없음.
  • RO Passport · RO Identity는 별도 인증 서비스와 동일 개념. 앞 절의 인증 분리 결정이 전략과 어긋나지 않음을 확인.

검토 중 — AIWAN은 RO IP 게임이 아닌 캐주얼 플랫폼이라 RO 포털 최상단 노출이 브랜드상 타당한지 별도 판단 필요. Star Wars KIDS는 같은 IP 내 분화라 조건이 완전히 같지는 않음. RO LIVE(KOL 방송)와 Web3는 구조상 자리는 있으나 이번 범위에서 제외.

GNB 항목 · PRONTERA 처리 · LIBRARY 진입 · 라인업 범위 · 게스트 관람은 확정. 몰입 형식은 디자인 결정 영역으로, 벤치마킹 문서에 검토 자료만 수록.
