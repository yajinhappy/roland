랜드 계정 · 그 위에 붙는 2계층 바인딩 · 두 계층의 유일성 규칙.

계정 모델

랜드는 비밀번호 미보유. 계정 바인딩은 전부 외부 제공자 경유 · 이메일만 포털이 직접 수집.

복구 경로

비밀번호 미보유이므로 계정 바인딩 전부 상실 시 이메일 외 복구 경로 부재. NC 소셜 데드락과 동일 구조 · 차이는 이메일 변경 가능 여부.

계정 바인딩과 게임 바인딩

랜드에 붙는 것은 소셜 3종 + GNJOY 9종뿐. 게임 계정은 계정 바인딩 대상이 아니며, 계정 바인딩에서 파생되는 게임 바인딩 계층에 위치. GNJOY 바인딩 시 매핑이 자동 생성되므로 분리선은 두 계층 사이.

게임 연결률의 상한

게임 바인딩은 계정 바인딩 없이 성립하지 않음. GNJOY 미바인딩 시 해당 지사 게임 조회 불가 · Google 미바인딩 시 Google 직결 게임 조회 불가. 게임 연결률을 올리려면 계정 바인딩률이 선행.

계정 열거 차단

가입 화면은 비로그인 상태에서 접근 가능. 이메일 중복 여부를 소유 증명 전에 노출하면 회원 이메일 여부가 외부에서 확인 가능해진다.

차단 전
  • 이메일 입력 → 즉시 중복 판정 노출
  • 임의 주소 반복 입력으로 회원 여부 수집
  • 미인증 이메일로 바인딩 제안이 서버에 남으면 타인 계정에 공격자 수단이 결합
차단 후
  • 이메일 입력 → 인증코드 발송 → 확인 → 그 다음 중복 판정
  • 발송 전 응답은 중복 여부와 무관하게 항상 동일
  • 중복 시 안내만 — 마이페이지 경로 제시 · 서버 pending 저장 금지

가입 흐름 내 로그인 유도 금지 — 자격증명 입력 화면의 분산은 피싱 내성 저하 요인. 마이페이지 바인딩 기능으로 동일 목적 달성.

이력 적재

동의 철회는 GDPR상 즉시 보장 대상 · 해제 자체는 제약 불가. 제약 대상은 재연결. 이를 위해 해제 시점 보존이 필요하며, 연결 지도 레코드는 삭제하되 일방향 해시 파생 식별자 + 해제 시각만 별도 보관. 보관 기간은 쿨다운 + α로 한정하고 처리방침에 명시.

이력 미적재 시 정책을 소급 적용할 데이터 자체가 부재. 정책 확정 이전이라도 적재는 선행.
