## 2. 왜 이 이름인가

### 2-1. 조사 결과 요약

국내 7개사 · 해외 9개사를 확인했다. 세 가지가 반복된다.

1. **디지털과 실물은 거의 항상 분리한다** — 16개 중 11개. 분리 이유는 브랜드가 아니라 **운영**이다(수령처 · 청약철회 · 운영 주체 · 확률 표기).
2. **이름에는 파는 물건이 들어간다** — Web · Online 같은 *장소*가 아니라 Item · Currency · Gear · Merch 같은 *대상*이 이름을 만든다.
3. **그릇 단어(Shop / Store)로는 구분하지 않는다.**

| 회사 | 디지털 | 실물 MD |
|---|---|---|
| Blizzard | Battle.net Shop | **Blizzard Gear Store** |
| HoYoverse | **Top-Up Center** | Merch (hoyo.global) |
| Riot | 인게임 상점 | Riot Games Store (merch.riotgames.com) |
| Krafton / PUBG M | Midasbuy 「PUBG Mobile Official Shop」 | PUBG 공식 merch store |
| 넥슨 | NEXON SHOPPING | **NEXON ESSENTIAL** (타이틀별 스토어) |
| 넷마블 | 게임별 **「공식 웹상점」** | 넷마블스토어 |
| 스마일게이트 | STOVE 스토어 | 스마일게이트샵 |
| 펄어비스 | — | 펄어비스 스토어 → **펄어비스 기어** |
| 데브시스터즈 | — | 쿠키런스토어 |
| 그라비티(현행) | GNJOY | 라그나로크 온라인 스토어 |
| Nintendo · Square Enix · Bandai Namco | 한 스토어에 통합 | 〃 |
| Ubisoft | Ubisoft Store 안에 **Currency** 카테고리 | Official Ubisoft Gear Shop |

### 2-2. 반례 — Supercell

| URL | 이름 | 파는 것 |
|---|---|---|
| `shop.supercell.com` | Official Supercell **Shop** | 실물 굿즈 |
| `store.supercell.com` | Supercell **Store** | 인게임 코인(젬) |

직관과 정반대다. **Shop / Store 차이로 두 영역을 가르면 안 된다.**

### 2-3. 폐기한 안과 이유

| 폐기 | 이유 |
|---|---|
| `KAFRA CENTER` | Center 는 **무엇을 하는 곳인지 말하지 않는다** |
| `WEB SHOP` | 업계 표준 용어는 맞지만 **사업자 용어**다. 유저 대면 라벨 사례가 없다 |
| `GOODS SHOP` | 영어권에서 goods 는 「물품 · 화물」. 표준은 Merch · Gear |

> **「웹샵」은 사내 문서 · 사업 논의에서 계속 쓴다.** D2C 웹상점을 가리키는 정확한 용어다. 바꾸는 것은 **유저가 보는 메뉴 라벨**뿐이다.

### 2-4. 확정 근거

**Kafra Store**
- 세계관 고유명사 — 상위 브랜드는 고유명사, 하위 내비게이션은 기능어(FF14 Mog Station · 쿠키런스토어 방식)
- 2007년부터 캐시샵 이름 `Kafra Shop` 으로 쓰여 **「라그나로크 공식 구매처」 인지가 이미 있다**
- EN / PT / ES **번역 불필요**
- 라그나로크 IP **전 타이틀 공통 NPC** — 타이틀 편중 없음

**In-Game Shop / Merch Shop**
- **용도 기준**이라 코인 · 포인트가 늘어도 구조가 버틴다. 형태 기준이면 **디지털 굿즈**가 어느 쪽에도 못 들어간다
- 어미를 `Shop` 으로 통일해 **동급으로** 읽히게 하고, 구분은 앞 단어(In-Game / Merch)가 진다
- `Store` 안에 `Shop` 둘 — **층위가 명칭에서 드러난다**

**제외 후보** — Item Shop(코인 수용 불가) · Collection(상품 라인명으로 읽힘 → 기획전 명칭으로 전용) · Gear Shop(RO 에서 장비로 읽힘) · Fan Shop · Gift Shop · Collectibles · Kafra Storage(구매 보관함으로 오인). 차선안은 **Merch & More**.

## 3. 카테고리 구조

```
Kafra Store
├─ [가로축] Featured : New · Limited · Event      ← 두 축 공통, 메인 상단
├─ In-Game Shop      게임에서 쓰는 것 · 계정으로 받기
│   ├─ Coins         권역 코인 (예: JoyCoin)
│   ├─ Packages
│   └─ Items         Costumes · Consumables · Services
│      ※ 타이틀 필터 : RO / ROZ / 추후 타이틀
└─ Merch Shop        소장하는 것 · 권역별 운영
    ├─ Merch         유형별 Plush · Figures · Apparel · Stationery · Pins & Acrylic
    │                캐릭터별 Poring Family · Baphomet · Kafra …
    ├─ Digital Goods 월페이퍼 · OST · 이모티콘
    └─ Bundles       Merch + Game Code   ← In-Game Shop 에 배너 교차 노출
```

- **Featured** — 두 축을 가로지르는 큐레이션. 기념 기획전은 `Collection` 명칭 사용(예: 24th Anniversary Collection)
- **Bundles** — 배송 상품이므로 Merch Shop 소속, In-Game Shop 에는 배너로 교차 노출
- **Coins** — 카테고리명은 권역 공통, 상품명만 현지화. 충전은 **기존 계정 지갑**과 연결
- **필터** — In-Game Shop 은 타이틀, Merch Shop 은 캐릭터

**세계관 마이크로카피(선택)** — 구매 아이템 보관함 `Kafra Storage` · Merch Shop 장바구니 `Pushcart`. 내비게이션 명칭은 기능어를 유지한다.

## 4. 진입 — 포털 GNB

```
포털 GNB   [ KAFRA STORE ▾ ]
              ├ IN-GAME SHOP   → 타이틀 × 권역 모달
              └ MERCH SHOP     → 이번 범위 밖
```

- **마우스 오버**로 열린다. 항목은 둘뿐이고 설명 · 배지를 붙이지 않는다
- **경유 페이지를 만들지 않는다** — 「카프라 센터」 같은 브릿지 페이지는 폐기
- `IN-GAME SHOP` 클릭 → **타이틀 × 권역 모달**(4열). 고르면 그 타이틀 × 권역의 인게임샵으로 간다

### 4-1. 타이틀 × 권역 (8종 확정)

| 타이틀 | 권역 |
|---|---|
| 라그나로크 온라인 | Korea · Global · Japan · Taiwan·HK·Macau · Thailand |
| 라그나로크 제로 | Global · Americas · Taiwan·HK·Macau |
| 라그나로크 뉴월드 | Taiwan·HK·Macau · Southeast Asia · Global |
| 라그나로크 오리진 클래식 | Asia |
| 라그나로크3 | Global |
| 라그나로크 M : Classic | Korea · Southeast Asia · Taiwan·HK·Macau · Global |
| 라그나로크 아이들 어드벤처 플러스 | Korea · Taiwan·HK·Macau · Global |
| THE 라그나로크 | Korea · Southeast Asia · Taiwan·HK·Macau · China |

- 카드 = **게임 배경 + 타이틀명 + 아래 걸치는 BI 원형**
- 내 권역에는 `내 지역` 배지. **파란 강조는 마우스 오버에서만** — 배지가 선택 상태로 읽히면 안 된다
- Korea 가 없는 타이틀(제로 · 뉴월드 · 오리진 클래식 · 라그나로크3)도 **카드는 보여준다**

**확정 필요 3건**
1. **권역 단위의 성격** — `Global · Asia · Americas · Southeast Asia` 는 묶음, `Korea · Japan · China · Thailand` 는 국가. 이 묶음이 **서비스 운영 단위인지 결제 단위인지**
2. **묶음 안의 통화** — `Americas` · `Southeast Asia` 는 한 권역에 통화가 여럿일 수 있다
3. **라벨 언어** — 권역명은 영문, 타이틀명은 한글. 섞어 둘지

## 5. In-Game Shop 화면 구조

| # | 화면 | 비고 |
|---|---|---|
| 01 | KAFRA STORE 진입 | GNB 메뉴 + 타이틀 × 권역 모달 |
| 02 | 인게임샵 메인 | 배너 · 메뉴바 · 한정 구역 · 상품 그리드 |
| 03 | 상품 상세 모달 | 확률형 / 비확률형 2종 |
| 04 | 담기 · 주문 드로어 | 결제 그룹 분리 |
| 05 | 통합 결제창 | 라그나로크 원페이 |
| 06 | 결제 완료 | |

### 5-1. 헤더 · 배너

- GNB 좌측은 **RO LAND 로고 하나**. `[‹ 포털]` · `[게임 · 지역]` 칩은 뺀다 — **배너가 대신한다**
- 배너 좌하단 **`라그나로크 온라인 ㆍ KOREA ▾`** — `▾` 를 누르면 01 의 타이틀 × 권역 모달이 그대로 열린다
- 배너 **우하단에 통화 셀렉터** — 가격 목록 바로 위다
- 메뉴바 탭 **3개** : 상품구매 · 구매내역 · FAQ

### 5-2. 한정 상품 — 구역 둘

| 구역 | 색 | 지표 |
|---|---|---|
| **기간 한정** `HOT!` | 붉은 계열 | 남은 기간(D-day) + 진행 바 · 마감 임박 순 |
| **수량 한정** `LIMIT` | 황 계열 | **계정당 구매 한도** |

- **구역을 나눈 이유** — 지표의 성격이 다르다. 기간은 **모두에게 같은 마감**, 수량은 **내 계정에만 걸리는 한도**다. 섞으면 급한 정도를 잘못 비교한다
- **수량 한정은 남은 재고가 아니다.** 한도 1 이면 `인 당 1개`, 2 이상이면 `구매 2/5개` + 진행 바로 내가 쓴 만큼을 보여준다
- **비로그인**은 쓴 개수를 모르므로 `인 당 5개` 로만 적는다 — `0/5` 로 쓰지 않는다
- **한도 소진**(`5/5`)이면 흐리게 + `[구매 완료]`. 목록에서 빼지 않는다
- **전체 재고 품절은 별개 상태**다 — 한도와 섞어 적지 않는다
- PC 는 두 구역을 나란히, TABLET · MO 는 위아래. 각 구역은 **가로 캐러셀** — 두 장이 꽉 차고 **세 번째가 10~20% 걸친다**

### 5-3. 상품 카드

| 상태 | 내용 |
|---|---|
| 평상시 | 썸네일 / 분류 · 상품명 / **하단 줄에 가격 좌 · `›` 우** |
| hover | 카드 **전면**을 아래에서 위로 그라데이션이 덮고, 분류 · 상품명 · 가격은 **자리를 지킨 채 글자만 흰색** |
| 클릭 | 카드 **어디를 눌러도** 상품 상세 모달 (우상단 `♡` 만 이벤트 분리) |

- **가격을 하단 줄에 둔 이유** — 가격이 곧 「살 수 있다」는 신호다. 높이 40px 고정이라 hover 에 카드가 흔들리지 않는다
- **버튼을 얹지 않는 이유** — 카드에서 결제까지 가려면 **확률 고지 · 수량 · 통화**가 필요한데 카드 안에 담을 수 없다. 카드는 **고르는 자리**까지만 맡는다

## 6. 구매 플로우

```
카드 클릭
   │
   ▼
상품 상세 모달   [♡]  [담기]  [구매하기]
   │                │         │
   │                │         └──────────────► 통합 결제창      (단건 즉시 구매)
   │                └─ 주문 드로어 ─ [결제하기] ► 통합 결제창      (복수)
   ▼
결제 완료
```

- **단건**은 결제 그룹이 하나뿐이라 드로어가 할 일이 없다 → **결제창 직행**
- **복수**일 때만 결제 그룹을 갈라야 하므로 드로어를 거친다
- 단건이어도 한정 상품 · PG 제한 상품은 **결제창이 상품 속성을 받아** 이용 가능한 결제수단을 좁힌다

### 6-1. 고지와 동의의 분리

| | 자리 | 내용 |
|---|---|---|
| **고지** | 상품 상세 모달 | 확률 정보 표 |
| **동의** | 통합 결제창 3행 | 체크박스 — **동의를 받는 유일한 자리** |

- 모달과 결제창 두 곳에서 받으면 **같은 동의를 두 번** 묻게 된다
- **어느 길로 들어와도 결제창을 거치지 않고 결제되는 경로는 없다** — 단건 즉시 구매도 마찬가지다

**결제창 동의 항목**

| | 문구 | 조건 |
|---|---|---|
| 상시 | `[필수]` 인게임 아이템은 우편 수령 후 청약철회가 제한됩니다. 결제 정보 · 지급 대상을 확인했습니다. | 항상 |
| 상시 | `[필수]` 만 19세 미만은 법정대리인의 동의가 필요하며, 동의 없는 결제는 취소될 수 있습니다. | 항상 |
| 조건부 | `[필수]` 이 주문에는 **확률형 상품**이 포함되어 있습니다. **확률 정보를 확인**했으며 구매에 동의합니다. + `[확률 보기]` | 확률형 포함 시 |

`[확률 보기]` 는 모달의 확률 표를 결제창에서 다시 연다 — 모달을 거치지 않은 단건 즉시 구매에서도 확인할 수 있어야 한다.

### 6-2. 주문 드로어

- **딤을 쓰지 않는다.** 담기는 반복하는 행동이라 담을 때마다 목록이 막히면 「닫고 → 담고 → 다시 열고」를 반복하게 된다. 뒤 화면 스크롤 · hover · 담기 모두 살아 있다
- 닫기 — `[✕]` · `ESC` · 드로어 밖 클릭
- **결제 그룹은 상품 속성이 정한다.** 유저가 묶고 푸는 것이 아니다

| 그룹 | 조건 |
|---|---|
| 함께 결제 | 일반 상품 |
| 따로 결제 | **기간 한정** · **수량 한정** · **PG 제한** 중 하나라도 걸리면 단독 그룹 |

- 박스를 쓰지 않는다 — 그룹 위에 **구분선** 하나(일반은 검은 선, 한정은 빨간 선). 스크롤로 잘려도 잘린 느낌이 없다
- 합계는 **그룹 안에서만** 합산한다. 전체 총액을 두지 않는다 — 한 번에 나가는 돈이 아니다
- 그룹마다 **주문번호가 따로** 생기고 **환불도 그룹 단위**다
- 수량 스테퍼는 행마다. 바꾸면 그룹 합계가 즉시 재계산된다. **수량 1 고정** 상품은 비활성

### 6-3. 통합 결제창

- **통화 셀렉터**는 「1 게임 · 상품 정보」 라벨 줄 오른쪽. 다른 통화를 고르면 확인 알럿

  > 통화 변경 시 환율 및 이용 가능한 결제 수단이 재적용되어 새로고침됩니다. 변경하시겠습니까?
  > `[취소]` `[변경하기]`

  - **취소** — 통화를 되돌린다. 결제 세션 유지
  - **변경하기** — 결제 세션을 다시 만든다. 선택한 수단이 바뀐 통화에서 쓸 수 없으면 해제된다
- **최근 결제 수단은 별도 행을 두지 않는다.** 목록 안 해당 타일에 **`최근` 배지**만 붙인다 — 1건이면 위아래에 같은 타일이 두 번 나와 두 번 결제한 것으로 오해할 여지가 생긴다
- 배지가 붙은 타일은 소속 그룹 맨 앞에 두고, 내부 스크롤이 걸려 있어도 **진입 시 그 타일이 보이는 위치로 자동 스크롤**한다
- 주문 상품은 **분류 / 상품명 / 단가 · 수량** 세 줄로 쌓는다. `× 1` 에 박스를 두르지 않는다 — 누를 수 있는 것으로 읽힌다

## 부록. 예상 질의

**주문은 권역별로 따로 하는데 굳이 하나로 묶는 이유는**
유저 입장에서 「라그나로크 상품 구매처」가 하나로 인지되는 것 자체가 목적이다. 굿즈 + 게임 쿠폰 번들처럼 두 영역을 넘나드는 상품이 늘고 있고(엔씨 · 넷마블 · 펄어비스 · 데브시스터즈 공통), **입구가 하나여야 교차 노출이 가능하다.**

**굿즈가 없는 권역은**
Merch Shop 비노출 또는 Digital Goods 만. 권역별 부분 적용이 가능한 구조로 설계했다.

**iRO 유저가 헷갈리지 않나**
iRO `Kafra Shop` 은 게임 내 캐시샵, `Kafra Store` 는 포털 레벨 상점으로 층위가 다르다. 포인트명을 분리하면 혼동 여지는 낮다.

**사내에서 쓰던 「웹샵」은 못 쓰나**
쓴다. D2C 웹상점을 가리키는 업계 표준 용어이고 사업 · 기술 문서에서는 정확한 말이다. 바꾸는 것은 **유저가 보는 메뉴 라벨**뿐이다.

**단건 구매가 드로어를 건너뛰면 결제 그룹 규칙이 빠지지 않나**
단건은 그룹이 하나뿐이라 가를 것이 없다. 한정 · PG 제한 같은 제약은 **결제창이 상품 속성을 받아** 결제수단을 좁히는 방식으로 유지된다.

**확률 동의를 결제창에만 두면 모달을 안 본 사람은**
결제창 동의 줄에 `[확률 보기]` 를 둬서 그 자리에서 확률 표를 연다. 확인하지 않고는 체크할 수 없다.
