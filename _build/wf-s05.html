ST-05 · 라우팅 & 한도 정책

1채널 선택법인 활성화

본사가 등재한 MID의 채널 중 쓸 것만 지사가 켠다. MID를 등록하면 채널이 통째로 딸려오는 게 아니다.

상속MID 채널 목록(본사) → 법인 활성화(지사) → 게임별 활성화(지사)
방향아래로 갈수록 좁아지기만 한다 — 법인에서 끈 채널을 게임에서 켤 수 없다
순서드래그로 변경 · 1순위가 결제창 기본 선택
긴급 차단지사가 자기 법인 채널을 끌 수 있어야 한다 — PG 장애 시 본사를 기다릴 수 없다
Hive 대응
동일「설정된 PG사는 삭제할 수 없고 비활성화만 가능」 — 삭제 없이 토글
2채널별 최소 · 최대지사 설정

PG 물리 제약 안에서 지사가 더 좁게 정한다. 좁히는 이유는 채널마다 다르다.

선불카드권종 상한 — 30,000 → 3,000. 유통되는 카드 권종을 넘는 금액은 결제가 안 된다
가상계좌하한 상향 — 30 → 500. 소액에서 이체 수수료가 결제액을 역전한다
편의점하한 상향 — 비동기 입금 CS 비용이 소액에서 수익을 넘는다
검증PG 물리 제약을 넘어서 넓힐 수 없다 — 입력 단계에서 거부
3게임별 재정의4계층

같은 채널이라도 게임마다 금액 범위가 달라야 할 수 있다 — 유저 연령대 · 객단가 · 상품 가격대가 다르기 때문. 재정의하지 않은 게임은 법인 기본을 상속한다.

범위법인 × 게임 × 채널
허용 방향좁게만 — 넓히거나 법인에서 끈 채널을 켜는 것은 불가
3가지 재정의금액 범위 축소 · 채널 사용 안 함 · 우선순위 변경
사유 기록필수 — 왜 좁혔는지가 없으면 인수인계 시 아무도 못 건드린다
막지 않으면 법령 위반이 난다

게임별 설정이 법정 한도나 PG 제약을 넘어 넓혀지면 지사 운영자 실수 하나로 위반이 발생한다. 시스템이 입력 단계에서 거부해야 한다.

4실효 한도 미리보기계산

4계층을 겹쳐 최종 얼마인지와 어느 계층이 걸렸는지를 보여준다. 계층이 4개면 사람이 머릿속으로 계산할 수 없다.

계산실효 하한 = max(하한들) · 실효 상한 = min(상한들)
표기각 계층의 범위와 어느 계층이 하한 · 상한을 결정했는지 명시
입력게임 × 채널 × 연령 3개 축
D2C진입 경로 한도는 별도 축이라 결과에 하나 더 겹친다
5법정 한도 · 진입 경로지사 소유

현지 법령은 지사가 안다. 본사는 한도 룰 기능만 제공하고 값은 지사가 넣는다.

판정 시점결제창 진입 전 — 초과 시 사유 코드 반환
누적 기준계정 단위 — 여러 게임 합산
연령회원·인증의 본인확인 결과 참조. 미확인 계정은 청소년 기준 적용
D2C누적 추적 불가 → 건 단위 통제만. 고액 경로가 아니다
6예상 노출 미리보기진단

이 화면의 핵심 도구. 게임 × 상품 × 금액을 넣으면 유저가 실제로 볼 목록과 제외된 채널이 몇 번 필터에서 걸렸는지를 표시한다.

목적「켰는데 왜 안 보이냐」 문의를 이 화면에서 차단
8단계 필터MID 풀 → 법인 활성화 → 게임 활성화 → Capability → 금액 범위 → 한도 → PG 상품 등록 → 헬스체크
결과 0건「결제수단 없음」도 정상 상태다 — 사유와 대안을 함께 표시
Failover는 환불 가능성을 바꾼다

1순위가 죽어 우회할 때 두 채널의 Capability가 다를 수 있다. GVC는 전 채널이 환불 불가라 문제가 없지만, GGA는 3순위(편의점 현금)만 불가라 우회 시 자동 환불 가능 상품이 환불 불가로 바뀐다. 후보는 동일 등급 안에서만 선정하고, 불가피하면 고지 팝업을 다시 띄워 동의를 새로 받는다. 동의 거부 시 처리는 미확정.
