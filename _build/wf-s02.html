ST-02 · PG 계약 & MID 관리 본사 전용

1본사 전용 화면권한

마스터 계약 주체가 본사이므로 키 세팅도 본사가 한다. 지사는 이 화면을 조회 전용으로만 열 수 있다.

본사머천트 등록 · 키 세팅 · PG 물리 제약 등재 · 지원 PG 목록 관리
지사마스킹 조회 · Capability · MDR · 정산 주기 확인 · 채널 토글(개방 시)
지사 불가키 원문 조회 · 머천트 추가 · 물리 제약 변경
계약은 지사 명의 · 협상과 키는 본사
이유지사가 PG 포털에서 직접 키를 받으면 본사가 발급 조건을 모르게 되고 MDR 기준값을 검증할 수 없다
효과협상력(그룹 물량)과 세무 분리(지사 명의)를 동시에 유지
2머천트 등록 폼모달

API Key · Secret · 웹훅 URL 3종으로는 라이브 운영이 안 된다. 4개 그룹 · 20개 항목을 PG 제공 자료에서 받아 등재한다.

① 자격증명머천트 ID · API Key · Secret · 웹훅 서명 시크릿 · Hash Key/IV · 인증서 · sandbox/live 2세트
② 엔드포인트Base URL · 서명 알고리즘 · 조립 규칙 · 웹훅 발신 IP 대역
③ 상거래통화 · 소수점 자릿수 · 최소/최대 · 주문번호 포맷 · 사전등록 요구 · 상품코드 규칙
④ 정산 · 환불MDR · 주기 · 리포트 수령 방식 · 취소 지원 · 취소 가능 기간
빠지면 라이브에서 바로 사고 나는 2개

소수점 자릿수 — KRW · JPY는 0자리인데 2자리로 처리하면 100배 결제가 된다.
웹훅 서명 시크릿 — API Secret과 같은 값을 넣으면 웹훅 검증이 전부 실패해 배송이 멈춘다.

등록 조건연결 테스트 통과 후에만 저장. 실패 상태로는 등록되지 않는다
세트 수법인 × PG × 환경 — 머천트 8건이면 16세트
3Secret Key 보관보안

인증키는 KMS Vault(HSM)에 암호화 저장되고 화면에는 앞 일부만 마스킹 노출된다. 등록 후 원문을 되읽는 경로는 없다.

복원불가 — 분실 시 PG사 재발급 후 교체 등록
주입세션 생성 시 백엔드가 메모리 상에서만 주입 — 프론트로 내려가지 않는다
인증서 만료만료일을 그리드에 노출 — SoftBank 등 인증서 기반 PG의 갱신 누락 방지
감사키 조회 · 교체 이력 불변 기록
4PG 물리 제약기준값

한도 4계층의 1계층. 지사가 어떤 설정을 해도 이 범위를 넘을 수 없다.

최소 · 최대머천트 × 채널 × 통화 단위. Step 4 상품 가격 검증과 Step 5 채널 한도의 상한
소수점통화별 자릿수 — 결제 금액 전송 포맷을 결정
주문번호 포맷MyCard는 30자 · 영대문자 — 현재 tx_gravity_… 형식이 통과하지 못한다
Hive 대비 개선점
Hive「통화별 최저 · 최고 결제 금액이 지정되어 있으므로 상품 가격 설정 시 주의」 — 안내로 끝난다
결과범위 이탈 상품이 유저의 결제 시도 시점에 에러로 드러난다
포털이 값을 등재해 상품 등록 검증 + 결제창 필터로 시스템이 차단
5상품 사전등록 요구플래그

「모든 PG 콘솔에 상품을 등록한다」는 전제는 틀렸다. 요구하는 PG만 대상이며, 이 플래그가 그 판별 기준이다.

불필요토스 · Stripe · PayPal · SoftBank · 2C2P — 금액만 보낸다
요구MyCard · GASH · 편의점 현금 — 상품 코드를 사전 등록해야 결제가 성립
상품코드 규칙길이 · 문자셋. 전 지원 PG의 교집합이 SKU 코드 체계를 제한한다
연동이 플래그가 ST-00 워크리스트와 결제창 필터 7번의 입력값
6채널 토글라이브 토글

3계층(법인 · MID · 채널) 중 런타임에 바뀌는 유일한 값. 끄면 결제창에서 즉시 사라진다.

반영1초 내 — Circuit Breaker
자동 차단헬스체크 연속 3회 타임아웃 시 시스템이 스스로 끈다
복구수동 재개만 — 자동 복구는 장애 중 트래픽을 되돌려 보낸다
진행 중 세션발급된 세션은 만료까지 유효 — 차단은 신규 세션에만 적용
확정 필요 — 지사 개방 여부

키는 못 봐도 자기 법인 채널 ON/OFF는 지사에 열어주는 것이 현실적이다. PG 장애 시 본사를 기다릴 수 없다. 다만 이 화면 자체가 본사 전용이므로, 지사용 토글은 ST-05(라우팅 · 한도)에 두는 것이 맞다.
