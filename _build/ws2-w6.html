구매내역 상점으로 돌아가기
수령 방법은 하나다
방식서버 검증 완료 즉시 게임 내 계정 우편함으로 자동 발송한다
회원 · 비회원동일하다 — 양쪽 모두 결제 전에 서버 · 캐릭터를 확정하므로 화면이 갈리지 않는다
진입통합 결제창에서 자동 복귀하는 화면이다 — 유저가 직접 진입하지 않는다
1완료 메시지안내

서버 검증 완료 후 노출한다. 수령 안내를 메시지에 포함한다.

문구구매하신 아이템이 게임 내 우편함으로 발송되었습니다
보조 문구게임에 접속해 우편함에서 수령해 주세요
검증 지연「처리 중」 상태를 노출하고 완료 시 자동 갱신한다
환불 안내「결제 완료 후 자동 환불이 제공되지 않으며, 환불 문의는 고객센터로 접수해야 합니다」 — 결제창 고지와 동일 문구를 완료 화면에도 노출한다
2수령 방법핵심

이 화면의 본체다. 어느 캐릭터로 보냈는지를 명시한다.

표기계정 우편함 발송 완료 + 서버명 · 캐릭터명 — 입력은 캐릭터 ID로 받되 확정 이후 화면은 캐릭터명으로 표기한다
근거결제 전에 확정한 지급 대상을 그대로 보여준다 — 유저가 어디서 받는지 알 수 있다
중복 배제수령 대상을 여기서만 노출하고 주문 상세에는 넣지 않는다
발송 실패재발송 대상으로 표기하고 고객센터 안내를 노출한다
3주문 상세내역

거래 정보만 담는다. 수령 정보는 위 카드에서 이미 노출했다.

항목주문번호 YYYYMMDD-일련번호 / 구매일시 / 상품 / 결제 금액 / 결제수단
결제 금액결제창에서 확정된 통화로 표기한다
결제수단PG 응답값을 그대로 표기 — 신용카드 신한 · 일시불
MO · TABLET세로 스택 · 아코디언으로 접을 수 있게 한다
4액션 버튼이동

둘만 둔다.

구매내역구매내역 탭으로 이동 — 비회원은 인증 절차를 거친다
상점으로웹샵 메인으로 이동 · 선택 상품 초기화
비회원 주문번호 안내

비회원 주문은 계정에 귀속되지 않는다. 구매내역 조회에 주문번호가 필요하면 이 화면에서 보관 안내를 노출해야 한다. 조회를 서버 + 캐릭터 인증만으로 처리하면 안내가 불필요하다 — 구매내역 탭의 비회원 조회 인증 방식 확정과 함께 정한다.
