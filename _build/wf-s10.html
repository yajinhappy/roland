SHOP · D2C 다이렉트 웹샵 (비로그인)

1웹샵 컨테이너웹 스토어

앱 마켓 인앱결제를 우회해 지사 직정산 PG로 결제하도록 유도하는 공식 웹 채널. 로그인 없이 결제까지 완결된다.

수수료IAP 30% → 직정산 PG 2.1~5.5%
법인 확정헤더 리전이 아니라 선택한 게임 서버가 결정 — 리전 표시는 결과일 뿐
반응형PC 4열 → MO 2열. 모바일 웹 유입 비중이 높은 채널
2보너스 혜택 배너배너

수수료 절감분의 일부를 ＋10% 추가 재화로 환원한다는 것을 최상단에 고지한다. 유저가 웹샵으로 옮겨올 유일한 동기다.

지급배송 웹훅의 bonus_quantity 로 자동 포함
재원보너스율은 MDR에 종속 — 수수료가 바뀌면 정책도 재계산
주의앱 마켓 심사 정책상 인앱에서 이 배너로 유도하는 표현은 별도 검토 필요
3비로그인 캐릭터 검증기REST API 호출

게임 서버 POST /v1/portal/character/verify 를 실시간 호출해 캐릭터 실존을 확인한다. 이 화면의 핵심이자 D2C의 유일한 신원 확인 수단.

입력 폼이 갈린다상품의 지급 단위(ST-04 설정)에 따라 이 영역 구성이 바뀐다
캐릭터 지급게임 · 서버 · 캐릭터명 3개 입력 → POST /character/verify. 계정 정보를 묻지 않는다
계정 지급게임 · 계정 식별자(아이디 또는 UID) 입력 → 계정 존재 확인. 서버 · 캐릭터를 묻지 않는다
미존재결제창 진입 원천 차단 — 오타 상태로는 다음 단계가 없다
점검 중서버 점검이면 점검 안내 팝업 — 검증 실패와 구분
SLA응답 500ms 미만. 초과 시 이탈로 직결된다
4검증 완료 메타 카드상태 정보

캐릭터명 · 레벨 · 직업 · 길드 · GUID를 되돌려 보여 오충전을 유저 스스로 잡게 한다. 타인 캐릭터를 입력했다면 이 카드가 선물 대상 확인 화면이 된다.

캐릭터 지급외형 · 레벨 · 직업 — 동명 캐릭터를 구분할 수 있는 최소 정보
계정 지급계정 식별자 마스킹 · 연결 캐릭터 수 — 「이 계정의 모든 캐릭터가 사용 가능」 문구 필수
노출 금지지사명 · 법인 코드는 표시하지 않는다 — 유저가 모르는 개념이다. 매출 귀속은 내부 처리로만
재확인결제창 상단에 같은 카드를 한 번 더 노출 (PAY 화면 참조)
5구매 버튼 · 결제창 호출체크아웃 트리거

통합 Hosted Checkout 모달을 호출한다. 이 시점에 세션 토큰이 발급되고 금액 · 통화 · 법인이 15분간 봉인된다.

선행 조건캐릭터 검증 완료 — 미검증 상태에서는 비활성
채널 로드해당 법인의 활성 채널만 동적 구성 (PAY 화면 3번)
가격 표기GVC는 세금 포함가. GVI(북미)만 세전가라 결제창 총액이 카드 가격보다 크다 — 정상 동작
