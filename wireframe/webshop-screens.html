  • 비로그인 : 아이템별 쿠폰 번호를 세로 카드형으로 나열 (상품명 → 코드 → [복사] 2줄 배치)

캐릭터 인증비로그인
  • 로그인 없이 구매하므로, 아이템을 받을 캐릭터를 직접 인증하는 절차가 필요
  • ① 서버 선택 → ② 캐릭터 ID 입력 후 [인증번호 발송] → ③ 인게임 시스템 메시지로 받은 6자리 번호 입력 후 [확인]
  • 인증번호 발송 대상 캐릭터는 게임에 접속 중이어야 함
  • 인증번호 유효시간 3분, 만료 시 [재발송]. 연속 발송은 횟수 제한(어뷰징 방지)
  • 인증 완료 시 ① ~ ③ 입력 영역이 '✓ 캐릭터 인증 완료 (서버 / 캐릭터명)' 표기로 대체

  • 아이템은 로그인 계정의 우편함으로 발송되며, 수령 캐릭터는 게임 접속 후 우편함에서 지정
  • 수령 대상 계정(마스킹 ID)만 확인용으로 표기
  • 캐릭터 선택 단계가 없으므로 연결 캐릭터 유무와 무관하게 결제 진행 가능

  • 팝업 차단 감지 시 안내 문구 및 재시도 버튼 노출
  • 결제창이 열려 있는 동안 당사 화면은 '결제 진행 중' 대기 상태 유지
4
결제 요청 — 그룹 코드 전달국내
  • 웹 상점에서 고른 결제 그룹 코드(CARD · EASY_PAY · MOBILE)와 주문 정보를 서버로 전달
  • 전달 항목 : 주문번호 / 권역 / 통화 / 결제 금액 / 결제 그룹 코드 / 수령 방식
  • 어느 PG로 보낼지는 서버가 권역 · 그룹 기준으로 판단 — 화면은 PG를 알지 못함
  • 서버가 회신한 결제창 주소로 이동 (PC 팝업 / 모바일 · 태블릿 전체 전환)
  • 수단 추가 · PG 교체 시 서버 설정만 변경되며 화면 수정 불필요

PG 결제창 — 외부 팝업국내
  • PG사가 제공하는 별도 브라우저 팝업 창 (자체 URL · 자체 UI)
  • 당사 디자인 · 퍼블리싱 대상이 아님. 호출 파라미터(주문번호 / 금액 / 상품명 / 반환 URL)만 정의
  • 좌측 결제 금액 요약 + 우측 결제수단 선택의 2단 구성
  • 창 크기 · 위치는 PG 스펙에 따르며, 모바일은 팝업 대신 전체 페이지 전환 방식 적용

  • 노출 결제수단은 PG 계약 조건에 따라 결정
  • 국내는 이 단계가 PG 결제창 안에 있으므로, 당사 화면에는 결제수단 선택 UI가 없음

카드사 · 할부 · 한도 안내 (PG 제공)국내

  • 노출 대상 : PayPal · Xsolla · EBANX · Alipay · Razer Gold (1차 기준, 추후 확장 가능)
  • PG사 로고 타일 그리드로 노출하고 선택 시 테두리 강조
  • 하단에 결제 금액(현지 통화)을 고정 노출하고 [Next] 로 다음 단계 진행
  • 미선택 시 [Next] 비활성
  • 노출 PG사 목록은 접속 권역 · 통화에 따라 다르게 구성 (관리자 설정 대상)
9
PG사 결제창 — 외부 팝업해외
  • [Next] 클릭 시 선택한 PG사의 결제창을 팝업으로 호출
  • 화면 구성은 각 PG사 스펙을 따르므로 당사 화면정의 대상이 아님 (세부 화면 정의 없음)
  • 호출 방식은 국내와 동일하며, PG사별 연동 파라미터만 개별 정의
10
결제 결과 콜백 · 서버 검증공통
  • 결제 완료 / 취소 / 실패 시 팝업이 닫히고 당사 결과 화면으로 리다이렉트
  • 성공 여부는 PG → 당사 서버 간 서버 검증(Webhook)으로 최종 확정
  • 검증 완료 후 아이템 지급. 검증 실패 시 결제 취소 처리 및 안내
  • 실패 · 취소 시 주문은 '결제 실패 / 취소' 상태로 기록하고 상점으로 복귀

1
완료 메시지
  • 서버 검증 완료 후 '결제가 완료되었습니다' + 수령 안내 노출
  • 로그인 : '구매하신 아이템이 게임 내 우편함으로 발송되었습니다.'
  • 비로그인 : '쿠폰 번호가 발급되었습니다. 게임에서 쿠폰을 등록해 아이템을 수령해 주세요.'
  • 검증 지연 시 '처리 중' 상태 화면을 노출하고 완료 시 자동 갱신
2
우편함 발송로그인
  • 서버 검증 완료 즉시 게임 내 계정 우편함으로 자동 발송 — 별도 등록 절차 없음
  • '✉ 게임 내 계정 우편함 발송 완료' + 수령 계정(마스킹 ID) 표기 — 캐릭터명은 표기하지 않음
  • 우편 보관 기간 · 미수령 시 처리 정책은 게임 우편 정책을 따름 (기간 명시 여부 협의 필요)
  • 발송 실패 시 재발송 대상으로 표기하고 고객센터 안내 노출
2
쿠폰 번호 발급비로그인
  • 서버 검증 완료 시 아이템별로 쿠폰 번호를 개별 발급 — 주문 1건에 여러 아이템이 있으면 쿠폰도 여러 개 노출
  • 수량이 2개 이상인 아이템은 수량만큼 발급하고 '상품명 (1/2)' 형태로 구분 표기 (예 : 고급 스킬북 x2 → 쿠폰 2개)
  • 목록 구성 : 상품명 + 쿠폰 번호 + [복사] 한 행. 상단에 총 발급 개수와 [전체 복사] 제공
  • [복사] 버튼 제공 — 클릭 시 클립보드 복사 후 '복사되었습니다' 토스트 노출 (게임 내 쿠폰 등록창에 붙여넣기)
  • [전체 복사]는 '상품명 : 쿠폰번호' 줄바꿈 형태로 일괄 복사
  • 표기 형식 : 4자리 × 4블록(예 ABCD-1234-EFGH-5678), 대문자 · 숫자 조합. 혼동 문자(O · 0 · I · 1) 제외
  • 쿠폰 번호는 이메일로도 발송하며, 화면 이탈 후에는 구매 내역 조회로 재확인
  • 발급 개수가 많을 경우(예 10개 초과) 목록 스크롤 처리 — 노출 상한은 운영 협의 후 확정
  • 1회 사용 · 재발급 불가. 유효기간 · 사용 완료 후 상태 표기(사용 완료 / 만료)는 쿠폰 시스템 정책 확인 후 확정
  • 결제 취소 시 미사용 쿠폰은 즉시 폐기, 사용 완료 쿠폰은 취소 불가 (고객센터 접수 기준)
